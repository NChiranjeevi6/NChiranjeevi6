# Daily Log

One short note per day: what I learned, fixed, or built. Real work only, so the contribution graph and snake reflect real activity.

Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD.md` (e.g. `2026-10-28.md`) and commit it.

## Ideas for a 10-minute daily entry
- A sanitized ticket and how it was fixed
- One MITRE ATT&CK technique and how you would detect it
- One Splunk SPL query or Wazuh rule you wrote
- One Linux hardening, firewall or IAM concept you practiced
- Notes from your CyberWarFare Labs C3SA course
